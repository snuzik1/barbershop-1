# Barber House

Barber House — учебный проект современного сайта барбершопа с главной страницей, навигацией, каталогом услуг и панелью администратора.

Проект создан для практики HTML, CSS, JavaScript, работы с интерфейсами, локальным хранением данных и базовой логикой управления контентом.

## Возможности

Сайт включает главную страницу с информацией о барбершопе, раздел с услугами, цены, информацию о компании и контактный блок.

В навигации используются якорные ссылки, благодаря которым пользователь может быстро перейти к нужному разделу страницы.

На сайте также присутствует скрытая ссылка на административную панель в нижней части страницы.

## Панель администратора

Административная панель позволяет управлять услугами барбершопа.

Модератор может:

- добавлять новые услуги;
- изменять существующие услуги;
- удалять услуги;
- изменять описание;
- изменять цену;
- просматривать текущий список услуг.

После изменения данных они отображаются на главной странице.

## Технологии

- HTML5
- CSS3
- JavaScript
- LocalStorage
